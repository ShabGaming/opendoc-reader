# Code of Conduct

OpenDoc Reader follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). That document is adopted here by reference. Please read it; it describes the behavior we expect and the behavior we do not accept.

## Scope

This applies to every space the project runs: issues, pull requests, discussions, code review, and any other channel that carries the project's name. It also applies when someone represents the project in public.

## Reporting

If you see or experience behavior that breaks the Covenant, report it privately to the maintainer, [@ShabGaming](https://github.com/ShabGaming), using the contact method on their GitHub profile. Please do not report it in a public issue or discussion. Include links to the relevant comments or pull requests and a short description of what happened.

## What happens next

The maintainer reads every report, keeps it confidential, and replies to the reporter. Depending on the situation the response can be a private word with the person involved, a warning, removing comments, or a temporary or permanent ban from the project's spaces. The enforcement guidelines in the Covenant describe these steps in more detail.

If the report is about the maintainer, say so in your message and ask for it to be handled by someone else. The project is small, so there may be no one else to hand it to. In that case you can contact GitHub Support.
