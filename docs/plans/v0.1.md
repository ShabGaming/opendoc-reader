# v0.1 build plan

Status: agreed, 2026-10-15. Scope comes from the README roadmap and [architecture.md](../architecture.md); the UI follows [design.md](../design.md). Each task below is sized to be one pull request (S: under a day, M: one to two days, L: three days or more) and can be copied into a GitHub issue as written.

v0.1 is done when a non-technical user on Windows (NVIDIA or CPU only) or an Apple Silicon Mac can install the app, let it pick and download a model, drop PDFs and images, watch them convert, review each page next to the original, and get a Word file and a Markdown file next to the original.

## Decisions for v0.1

Agreed on 2026-10-15:

- **Math in Word:** our own LaTeX -> MathML -> OMML converter for common constructs, falling back to the LaTeX text. If it slips, display math ships as LaTeX text and the converter moves to v0.2.
- **Page furniture:** running heads and page numbers are left out of Word and Markdown exports. Footnotes are kept at the end of their page's section.
- **AMD and Intel GPUs on Windows:** run on CPU by default. The Vulkan build is an opt-in experimental setting.
- **Fast tier language:** default model only, no language dropdown in v0.1.
- **Title bar:** native decorations on both platforms.
- **Process:** after M0, three lanes run in parallel on local branches and are merged into `main` after review and testing. Nothing is pushed until the maintainer has tested the result.

## Lanes and order

Work runs in three lanes that only meet at two written contracts (M0). After M0 they proceed in parallel; M5 joins them.

```
M0 contracts ──┬── M1 Rust core (runtime, downloads, probe, queue) ──┐
               ├── M2 Engine pipeline ── M3 Exporters ───────────────┼── M5 integration, quality, release
               └── M4 UI (against mocked commands) ──────────────────┘
```

## Risks

- **PaddleOCR on macOS arm64.** paddlepaddle 3.3.1 publishes a cp312 macOS arm64 wheel, but the pipeline has only been run on Windows. Run M2-4 on the Mac early.
- **Math in Word.** M3-1 is the least certain task. If it slips, v0.1 can ship display math as the LaTeX text and fix it in v0.2.
- **Engine environment size.** The spike's env was about 1 GB with paddle. Setup must show the real number.
- **Vulkan backend.** Untested (no AMD or Intel GPU), so it is opt-in and labelled experimental in v0.1.
- **Unsigned builds.** SmartScreen and Gatekeeper prompts remain; the user guide covers them.
